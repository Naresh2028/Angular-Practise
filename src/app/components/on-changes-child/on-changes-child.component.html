📘 Quick Notes: ngOnChanges Lifecycle Hook

ngOnChanges() is an Angular lifecycle hook that runs whenever one or more data-bound @Input() properties change.

Key Points to Remember:
  • Execution Order: Runs before ngOnInit() on initial load (if inputs exist) and every time an @Input() value updates.
  • SimpleChanges Parameter: Gives access to currentValue, previousValue, and isFirstChange() for each changed input.
  • Primitive vs. Object Inputs: Triggers reliably on primitive values (number, string, boolean). For objects or arrays, it only triggers if the object reference changes—not when inner properties are mutated.
  • Best Use Case: Reacting to parent input updates to trigger side effects like fetching fresh API data (as done here with productId).
Note on @ symbol in Angular 16+: Using &#64;Input() in HTML prevents Angular's built-in control flow parser (@if, @for) from throwing a template syntax error.
